## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system

You can verify your Python installation by running:

```bash
python --version
```

---

### Clone the Repository

```bash
git clone https://github.com/omkarpawar2002/Core-Python.git
```

---

### Navigate to the Repository

```bash
cd Core-Python
```

---

### Run Any Python File

```bash
python filename.py
```

Example:

```bash
cd Day_02
python coding_problems.py
```
